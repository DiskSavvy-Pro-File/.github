# DiskSavvy Pro — file classification on a disk you own

DiskSavvy Pro keeps one named board on the desk: the live groups, the category in front of you, and a short note the next operator can read. Extra dumps wait for their own title.

## Session Card

| Slice | What you do in DiskSavvy Pro | What remains |
|-------|------------------------|--------------|
| Arrival | Open DiskSavvy Pro and name today's storage desk | A titled category report |
| Focus | Keep only live groups on the DiskSavvy Pro board | A short type list |
| Check | Read DiskSavvy Pro disk analysis before a large category change | A confirmed storage desk |
| Handoff | Mark finished groups inside DiskSavvy Pro | A note for the next operator |

## How DiskSavvy Pro Sits

DiskSavvy Pro does not replace a guess about what filled the drive, the unlabeled type dump, or a report on a disk you do not own. It sits beside them as a named storage desk for one job: which file classification is live, which disk analysis still matches a category of files you own, and what the next operator should read.

## Traffic Light

| Signal | On the DiskSavvy Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named category report, short live group list | Continue the same file classification |
| Amber | Two disks mixed on one type list | Split the groups before a large change |
| Red | No title, no note, a guess about the drive | Stop and name the storage desk first |
| Clear | Handoff written, live groups few | Close DiskSavvy Pro and leave the storage desk |

## Open Order

1. Open the last DiskSavvy Pro storage desk, not a new empty category report.
2. Read the disk analysis and the last handoff.
3. Finish one visible file classification inside DiskSavvy Pro on a disk you own.
4. Write what changed, then close with fewer drive guesses than you found.
5. If the groups feel crowded, drop anything that belongs to a different DiskSavvy Pro disk.

## After a Week

A week in DiskSavvy Pro is not a larger guess about the drive. It is the same title, a shorter live group list, and a note that still makes sense before the next category report. Take finished groups off the live set so the next visit starts on the storage desk that is still open.

## Sign-off

- [ ] The DiskSavvy Pro workspace name is short enough to scan
- [ ] Only a disk you own sits on the file classification
- [ ] A second operator can read the category handoff
- [ ] The last DiskSavvy Pro category report still opens after a restart
- [ ] Finished groups are off the live DiskSavvy Pro set

## Field Note

DiskSavvy Pro is easier to trust when the storage desk stays smaller than the unlabeled type dump it came from. Name the category report, keep the live groups, finish one visible disk analysis, and write what changed.
